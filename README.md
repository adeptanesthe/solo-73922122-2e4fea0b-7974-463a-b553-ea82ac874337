# 野生动物追踪串号校正与计数台

面向野生动物视觉工程师的网页工具：纠正追踪串号（ID switch）造成的漏计 / 重复计数。
上传帧图片与检测框，标记“同只 / 异只”判断，调整关联代价参数，求解**全局最小**关联，
按轨迹条数给出动物计数；判断冲突时明确提示无解，不给计数。

内置**相邻帧色差校正**：自动曝光 / 自动白平衡会让同一背景在相邻帧呈现不同亮度与色偏，
直接比对毛色会失真。该功能以当前帧为参考，从两帧检测框外的背景估计各颜色通道的
**单调亮度映射**，校正下一帧并并排显示，供逐帧核查毛色。校正只读，
不改动原图、检测框、轨迹与计数。


## 使用流程

1. **数据**：上传 1~10 张帧图片 + 1 个检测 JSON（≤30 框），或点击“加载交叉遮挡示例”
   （追踪演示）/“加载曝光抖动示例”（色差校正演示）。
2. **按帧查看与标记**：←/→ 键或按钮切换帧；点击两个检测框（可跨帧）后选择
   “标记为同只 / 异只”，可随时清除。
3. **代价参数**：距离权重、外观权重、每条新轨迹罚分，均可调。
4. **求解**：点击“计算最优关联”。计算期间可继续修改判断与参数；
   任何修改会立即撤下旧结果，迟到的旧结果不会覆盖新输入（按输入版本号校验）。
5. **相邻帧色差校正**：在“5. 相邻帧色差校正”卡片点击“校正当前帧与下一帧”，
   并排查看参考帧（原图）与校正后的下一帧；两帧检测框均照常叠加显示。
   切换帧或切换会话会立即撤下旧预览，迟到的校正结果不会回填。

## 色差校正：样本与可靠性门槛

- **样本来源**：仅取两帧检测框并集（外扩 2 像素）以外的背景像素；
  饱和像素（任一帧任一通道 ≤6 或 ≥249）与变化区域（对每通道鲁棒线性变换的
  残差 >26 灰级，掩膜外扩 1 像素）一律不参与估计。
- **单调映射**：每通道按后一帧样本值分 24 箱取中位数，加权保序回归（PAVA）
  保证映射单调不减，再插值为 256 级查找表应用于后一帧。
- **拒绝条件**（提示“无法可靠对齐”，不显示校正图）：
  - 有效样本 < 300，或 4×4 网格中覆盖区域 < 10 格（样本须分散）；
  - 亮度跨度 p95−p5 < 48，或任一通道跨度 < 30（明暗层次不足）；
  - 2×2 子区域的局部映射与全局映射最大偏差 > 20 灰级（各区域映射矛盾）；
  - 后一帧检测框内动物像素超出可信标定范围（样本 p0.5~p99.5 外扩 8 灰级）
    的比例 > 2%（校正需外推，不可信）。
- 帧尺寸须一致且 ≤ 512×512，否则接口返回 400。
- 校正图仅保留最近一次结果，凭一次性 token 访问；新的校正请求（无论成败）
  会作废旧 token，迟到的结果无法在服务端或前端回填。

## 检测 JSON 格式

```json
{
  "detections": [
    {"id": "b1", "frame": 0, "rect": [x, y, w, h], "vector": [0.8, 0.1, 0.2]}
  ]
}
```

- `id`：框号（字符串或数字，全局唯一）
- `frame`：帧号，0 起，须小于上传图片数
- `rect`：`[x, y, 宽, 高]`，宽高为正
- `vector`：非零外观向量，所有框维度一致（≤512 维）

会话内可下载当前检测 JSON：`GET /api/sessions/{sid}/detections.json`。

## 模型与求解

- 约束：每框恰属一条轨迹；同一轨迹每帧至多一框；轨迹内相邻框帧差 1~2 且时间递增。
- 关联代价：`w_dist × 框中心距离平方 + w_app × (1 − 余弦相似度)`。
- 目标：所有关联代价 + 轨迹条数 × 新轨迹罚分，求**全局最小**。
- 方法：整数线性规划（SciPy `milp` / HiGHS）。
  “同只”用单位流强制可达（同轨迹），“异只”用 0/1 割变量强制不可达。
- 判断相互冲突（如两框同帧却标同只、同只与异只传递冲突）时返回**无解**，
  界面明确提示且不显示动物计数。
- 动物数 = 轨迹条数。

## 内置示例

- **交叉遮挡示例**（6 帧）：A（红）与 B（蓝）沿 X 形路径相向穿行，第 3 帧 B 被
  A 遮挡缺失检测、A 的外观向量被污染。正确结果为 2 条轨迹（2 只）：B 链需跨 2 帧
  连接（帧 2→帧 4）。该示例背景近乎单色，用于色差校正时会因“明暗跨度不足”被拒，
  可用来观察拒绝路径。
- **曝光抖动示例**（6 帧）：A（红棕）与 B（蓝灰）相向穿行、全程可见；每帧整体增益
  与红/蓝白平衡系数不同，模拟自动曝光与自动白平衡抖动。全部 5 对相邻帧均可通过
  色差校正的全部可靠性门槛。

默认参数（w_dist=1、w_app=10000、罚分=15000）针对交叉遮挡示例调优；
上传自有数据时请按图像尺度与外观向量区分度调整权重。

## API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/sessions` | 上传图片（`images`）+ 检测 JSON（`detections`），创建会话 |
| POST | `/api/example` | 创建交叉遮挡示例会话 |
| POST | `/api/example-exposure` | 创建曝光/白平衡抖动示例会话 |
| GET | `/api/sessions/{sid}` | 会话数据（含输入版本号） |
| GET | `/api/sessions/{sid}/frames/{i}` | 第 i 帧图像 |
| PUT | `/api/sessions/{sid}/judgments` | 整体替换同只/异只判断（版本 +1） |
| PUT | `/api/sessions/{sid}/params` | 更新代价参数（版本 +1） |
| POST | `/api/sessions/{sid}/solve` | 启动异步求解，返回任务 id 与输入版本 |
| GET | `/api/jobs/{job_id}` | 查询求解状态与结果（结果携带输入版本） |
| POST | `/api/sessions/{sid}/calibrate` | 校正相邻帧对 `{"frame": i}`（i 与 i+1），只读不改版本 |
| GET | `/api/sessions/{sid}/calibration/{token}/corrected.png` | 最近一次校正图（token 失效即 404） |

## 说明与限制

- 会话与任务保存在进程内存中，重启即清空（单用户工具定位）。
- 上限：10 帧、30 框、200 条判断、外观向量 512 维；色差校正帧尺寸 ≤ 512×512。
- 求解默认 60 秒时限；本规模（≤30 框）通常在毫秒级完成。
- 色差校正为逐对相邻帧的预览工具：校正图不落盘、不回写会话，
  也不参与追踪求解与计数。
